# ApexPlanet Data Analytics Internship – Task 1

## Data Immersion & Wrangling

This project is completed as part of the ApexPlanet Data Analytics Internship.

The objective of Task 1 is to understand the dataset, identify data quality issues, clean the data using Python and Pandas, perform basic transformations and feature engineering, and prepare an analysis-ready dataset.

---

## Dataset

The dataset contains sales transaction records with the following original columns:

- Order_ID
- Order_Date
- Customer_ID
- Customer_Name
- Age
- Gender
- City
- Product
- Category
- Quantity
- Unit_Price
- Total_Sales

The dataset contains 1,000 rows and 12 original columns.
